# Web Store Listing (copy-paste to Chrome Web Store)

## Short Description (132 chars max)
Highlight text on any webpage, add notes, and copy as markdown for LLM or note-taking apps. All data stays local.

## Detailed Description

Highlight and annotate any webpage — no account needed, no data uploaded.

FEATURES

- Highlight text on any webpage with one click
- Add notes to your highlights (Medium-style note UI)
- Review all highlights in a side panel
- Copy for LLM — formatted markdown with source context, ready to paste into ChatGPT or Claude
- Copy as Notes — clean list format for Notion, Obsidian, or any note-taking app
- Pick exactly which highlights to export — everything is selected by default, untick what you don't need
- Highlights restore automatically when you revisit the page
- Storage usage indicator so you always know how much space is used
- Works on all websites including SPAs (React, Next.js, etc.)

PRIVACY

- All data is stored locally in your browser
- No data is sent to any external server
- No analytics, no tracking, no accounts
- Open source (GPL v3)

TIPS

- Select text → click "Highlight" or "Note"
- Click a highlight to unhighlight or add/edit a note
- Cmd+Enter to save a note quickly (Mac)
- Use the side panel to review all highlights on the current page
- Data is stored locally — clearing browser data may delete your notes

PERMISSIONS

- storage: save highlights and notes locally
- activeTab / tabs: identify the current page
