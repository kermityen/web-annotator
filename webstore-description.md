# Web Store Listing (copy-paste to Chrome Web Store)

## Short Description (132 chars max)
Highlight text on any webpage, add notes, and copy as markdown for LLM or note-taking apps. All data stays local.

## Detailed Description

Highlight and annotate any webpage — no account needed, no data uploaded.

FEATURES

- Highlight text on any webpage with one click
- Add notes to your highlights
- Review all highlights in a side panel that opens on the page
- Pick exactly which highlights to export — everything is selected by default, untick what you don't need
- Copy for LLM — markdown with your quotes, your notes clearly labelled, and the source link, in the order they appear on the page
- Copy as Notes — a bullet list that pastes cleanly into Notion, Obsidian, or Apple Notes
- Copied links drop common tracking and login parameters (such as utm_ tags and access tokens)
- Per-site toggle — turn the extension off on sites where you don't want it
- Highlights restore automatically when you revisit the page
- Works on JavaScript-rendered sites (React, Vue, Next.js) — highlights are restored after the page finishes rendering
- Storage usage indicator so you always know how much space is used
- Browse every site you have annotated, and remove a site's highlights when you no longer need them
- Clear all highlights on the current page

PRIVACY

- All data is stored locally in your browser
- Websites cannot read your notes, including while you are typing one
- No data is sent to any external server
- No analytics, no tracking, no accounts
- Open source (GPL v3)

PERMISSIONS

- storage — saves your highlights and notes locally in your browser
- activeTab and tabs — reads the address of the current tab so highlights can be matched back to the right page
- Access to all websites — the extension needs to run on any page you might want to highlight. It reads the page only to show and restore your highlights, and nothing ever leaves your browser

TIPS

- Select text → click "Highlight" or "Note"
- Click a highlight to unhighlight or add/edit a note
- Press Cmd+Enter (Mac) or Ctrl+Enter (Windows and Linux) to save a note quickly
- Open the side panel to review all highlights on the current page

GOOD TO KNOW

- The website you are on can see which text you highlighted (not your notes) and that the extension is installed, because highlights are drawn on the page
- Notes are not encrypted. Anyone who can use your computer or your Chrome profile can read them
- There is no backup or sync. Uninstalling the extension or clearing browser data deletes your highlights and notes
- If a page hides text inside a passage you highlight, that text is copied too. Read what you paste before sending it to an AI
- Chrome does not let extensions run on its own pages, the Chrome Web Store, or the built-in PDF viewer
