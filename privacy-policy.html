Web Annotator — Privacy Policy

Last updated: 2026-03-31

Overview

Web Annotator is a browser extension that lets you highlight text and add notes on any webpage. Your privacy matters — this extension is designed to keep all data local.

Data Collection

Web Annotator does not collect, transmit, or share any personal data. Specifically:

  • No data is sent to any external server.
  • No analytics or tracking of any kind.
  • No cookies are set by the extension.
  • No user accounts or registration required.

Data Storage

All highlights and notes are stored locally in your browser using chrome.storage.local. This data:

  • Stays on your device only.
  • Is not synced to any cloud service.
  • May be lost if you clear browser data or uninstall the extension.

Clipboard Access

The "Copy for LLM" and "Copy as Notes" features write formatted text to your clipboard. This is a one-way, user-initiated action. The extension does not read from your clipboard.

Permissions

  • storage — to save highlights and notes locally.
  • activeTab / tabs — to identify the current page URL and title.

Third-Party Services

This extension does not integrate with or send data to any third-party services.

Changes

If this policy changes, the updated version will be published here.

Contact

For questions about this privacy policy, please open an issue on the project's GitHub repository.
